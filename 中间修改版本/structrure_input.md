# 全书目标（3–5条）
-1️以“数学思维”统摄人工智能的理性结构

通过揭示人工智能的核心在于数学化的建模与推理，引导读者理解AI并非神秘的黑箱，而是数学思想的自然延伸。让学生认识：每一个算法背后，都是一种数学思维的体现。

- 从“知其然”走向“知其所以然”

突破以往“只会用公式和代码”的学习方式，引导读者理解为什么要这样建模、为什么这样有效、为什么又有局限，培养从问题本质出发的理性分析能力。

- 建立“数学—算法—智能”的三层认知框架

系统阐明数学思维如何转化为算法逻辑，再如何在工程实现中体现为智能行为，帮助读者建立由抽象到实现的完整理解路径。

- 训练面向智能系统的理性建模能力

通过典型AI模型的剖析（如回归、分类、神经网络、Transformer等），引导学生体会模型选择、参数权衡与复杂性控制背后的理性判断，培养建模的思辨性与创造性。

- 以“思维”为核心，淡化“技术堆砌”

区别于传统技术导向教材，本书不过度讲解编程细节，而是让读者掌握算法背后的思想脉络与取舍原则，从而在技术更新迭代中保持“迁移性的理解力”。

- 将人工智能置于理性与伦理的双重坐标

在讨论算法与模型的同时，引导学生思考AI的边界与责任：人类理性如何定义“智能”，以及当AI参与决策时，我们如何保持判断与价值意识。

- 服务“新工科”与“通识教育”的融合目标

既能作为计算机、软件工程等专业课程的数学与思维基础教材，也能为非工科背景学生提供一个理解人工智能逻辑与理性框架的通识入口。

- 在教学中重构“思维训练”的课堂形态

设计富有启发性的讨论题与案例，促使学生在课堂上思考、提问、辩论、建模，让AI学习回归理性思考与创造性探索，真正实现“以思维为核心的教学转向”。
