## Prompt 1：对照式润色（带 diff 视图）

### 适用场景

* 针对**已经写好的 LaTeX 小节**（推荐：一个 `\subsection`），希望：

  * 语气更接近“课堂讲解体”；
  * 逻辑更顺畅，有适度过渡和思维引导；
  * 同时生成带 `diff` 的红删绿加视图，方便在 VSCode 对照修改。

### 使用方法（日常）

1. 在 VSCode 中选中一个 `\subsection` 的 LaTeX 原文。
2. 打开 Claude Code 面板（绑定 glm4.6）。
3. 输入本 prompt（可以用 snippet 一键展开），在最后补：

   ````text
   下面是原文：
   ```tex
   ...（这里粘贴原文）...
   ````

   ```
   ```
4. 发送，让模型按三段格式输出。

### Prompt 正文（粘给模型用）

````text
你是一位长期参与《人工智能的数学思维》书稿打磨的“学术教材编辑 + 人工智能教育专家”，已经熟悉本书的《书稿风格与编辑手册》。

【任务】
对我提供的一段 LaTeX 文本进行“对照式轻度润色”，目标是：
- 保留原有知识点和信息量，不大幅删减内容；
- 语气更接近通识 + 课堂讲解体，像一堂结构清晰、有温度的深度课；
- 修顺语句、补足必要的过渡和思维引导，缓解“过于凝练”的问题。

【硬性约束】
1. LaTeX 结构不变：
   - 不新增或删除 \\chapter、\\section、\\subsection 等结构命令；
   - 不修改或删除 \\label{...}、\\ref{...} 等标签与引用；
   - 不随意新增/删除环境（如 definition、figure、equation 等），只在环境内部修改文字。

2. 格式与缩进：
   - 尽量保留原有缩进与空行，方便在 VSCode 中做行级 diff。

3. 风格要求（严格遵守《书稿风格与编辑手册》）：
   - 像课堂讲解：有铺垫、有推理、有小结；
   - 每段尽量不超过 7 行，删除机械重复；
   - 适度添加过渡句和思维引导句，但不要密集堆叠；
   - 尽量使用主动语态，可以适度使用“我们 / 可以看到 / 换句话说”，但不要滥用；
   - 禁用空洞口号，避免使用“显然 / 不难发现”等带压迫感词语（除非在严格数学语境且已有充分铺垫）；
   - 时刻记住：读者可能来自社会学或文科，只在大一上过高数。

【输出格式（非常重要，请严格遵守）】
只输出以下三段内容，不要添加其它解释性文字：

1）原文备份你是一位擅长用例子和类比讲解抽象概念的 AI 教材作者，熟悉《人工智能的数学思维》的《书稿风格与编辑手册》。

【任务】
围绕我提供的“概念 / 结论 / 思想”，为本书生成若干**例子或类比**，用于帮助跨专业读者建立直觉。

【读者假设】
- 各专业本科生 / 研究生，以及程序员；
- 数学基础大致为“上过大学基础课，但已生疏”；
- 包含社会学、教育学、文科等非理工科读者。

【要求】
1. 每个例子 / 类比应满足：
   - 与原概念有清晰的对应关系；
   - 例子本身不复杂，读起来不会增加额外负担；
   - 尽量贴近日常生活或常见技术场景（如推荐系统、搜索、排队、投票等）。

2. 风格要求：
   - 语气温和、像课堂讲解，不搞悬疑文学；
   - 描述控制在 1–3 段内，避免过长。

【输出格式】
请给出 2–3 个候选，每个按以下结构输出：

- 例子 X：
  1）例子描述：用于直接写入书稿的那种表述；
  2）对应关系说明：原概念中的关键要素 A/B/C，在这个例子里分别对应什么；
  3）（可选）适用位置建议：更适合作为引入？中间解释？还是小结回顾？

下面是需要用例子/类比来解释的概念或原文片段：
%% 原文
```tex
（逐字贴回我提供的原文）
````

2）diff 视图
%% diff

```diff
- （原句1）
+ （修改后句1）
- （原句2）
+ （修改后句2）
```

说明：

* 用 - 开头表示删除或被替换的原内容；
* 用 + 开头表示新增或修改后的内容；
* 只需要对有修改的行给出 diff，不必覆盖整段原文。

3）修改后版本
%% 修改后

```tex

```

## Prompt 2：扩写到 1.5–2 倍（保结构，补解释）

### 适用场景

* 某一小节“太瘦”：结论有了，但：

  * 中间推理没有铺开；
  * 对跨专业读者不够友好；
  * 希望扩写到约原来的 1.5–2 倍篇幅。

### 使用方法

* 选中一个 `\subsection` 或其中的一大块文字。
* 用本 prompt（可用 snippet），在最后加上原文：

  ````text
  下面是原文：
  ```tex
  ...原文...
  ````

  ```
  ```
* 让模型只输出“扩写后的 LaTeX 版本”。

---

### Prompt 正文

````text
你是一位长期参与《人工智能的数学思维》书稿写作的作者合作者，已经熟悉《书稿风格与编辑手册》。

【任务】
在保持原有结构和立场不变的前提下，将我提供的这段 LaTeX 文本扩写到原来的大约 1.5–2 倍篇幅，使其：
- 对关键概念和结论有更充分的解释；
- 适度增加例子、类比或直观描述，照顾数学基础一般、跨专业的读者；
- 整体语气更接近“课堂讲解体”，像老师在黑板前慢慢铺陈。

【硬性约束】
1. LaTeX 结构不变：
   - 不新增或删除 \\chapter、\\section、\\subsection 等结构命令；
   - 不修改或删除 \\label{...}、\\ref{...} 等标签与引用；
   - 可以在现有环境内部插入句子或新段落。

2. 内容不改变原有结论和立场：
   - 不引入与原文矛盾的新观点；
   - 可以调整句子顺序，使逻辑更顺畅。

3. 风格要求（遵守《书稿风格与编辑手册》）：

## Prompt 3：结构诊断（不改文，只提建议）

### 适用场景

* 你觉得某一章或某一 section “太碎/太散/不顺”，但暂时不想改文字，只想：

  * 看清当前结构在讲什么；
  * 让模型指出小节划分、顺序、过渡的问题；
  * 给出一个“新结构草案”。

### 使用方法

* 把一个 `\section`（可以包含多个 `\subsection`）的 LaTeX 贴给模型。
* 使用本 prompt，强调“只分析，不改文”。

---

### Prompt 正文

```text
你是一位负责《人工智能的数学思维》整体结构把关的“学术编辑 + 结构工程师”，已经熟悉本书的《书稿风格与编辑手册》。

【任务】
对下面这段 LaTeX 文本（通常对应一个 \\section，包含若干 \\subsection）进行“结构与逻辑层面”的诊断与建议，不改写具体句子。

请按以下四个问题进行分析：

1）核心问题与关键信息
- 用 2–4 句话概括，这一部分整体想回答什么问题？想给读者留下什么“核心图景”？

2）现有结构的优点
- 当前小节划分、段落顺序有哪些值得保留的优点？（条列说明）

3）结构性问题与风险点
- 是否存在小节过碎、话题分裂的问题？
- 小节顺序是否合理？是否存在前后依赖关系不清晰的地方？
- 是否缺少从上一节到下一节的自然过渡？
- 是否有重要观点被拆散到多个地方重复出现？
- 术语或概念的引入顺序是否混乱？

4）重构建议与新结构草案
- 给出一个更合理的结构建议，包括：
  - 建议的小节顺序（可以用列表形式写出“推荐结构草案”）；
  - 建议合并或拆分的小节；
  - 指出在什么位置应该增加“引入段”或“过渡段”；
  - 简要说明每个小节“该解决什么问题 / 承接谁 / 为谁铺路”。

【重要】
- 这一轮只做结构诊断和建议，不生成修改后的 LaTeX 文本；
- 你可以引用原文中的小节标题或关键词来说明问题，但不要大段抄写原句。

请按以下格式输出（纯文本即可）：
1. 核心问题概述
2. 现有结构优点
3. 结构问题与风险点
4. 推荐的重构方案（包括一个简要的小节结构草案）

下面是需要诊断的 LaTeX 文本：
```

### 适用场景

* 某个概念/结论/思想已经有文字说明，但：

  * 跨专业读者可能还是觉得抽象；
  * 想多几个例子/类比来挑选；
  * 例子最好贴近日常或简单工程场景。

### 使用方法

* 把概念说明或原文片段贴给模型。
* 用本 prompt 要求：生成 2–3 个例子 / 类比，每个带“对应关系说明”。

---

### Prompt 正文

```text
你是一位擅长用例子和类比讲解抽象概念的 AI 教材作者，熟悉《人工智能的数学思维》的《书稿风格与编辑手册》。

【任务】
围绕我提供的“概念 / 结论 / 思想”，为本书生成若干**例子或类比**，用于帮助跨专业读者建立直觉。

【读者假设】
- 各专业本科生 / 研究生，以及程序员；
- 数学基础大致为“上过大学基础课，但已生疏”；
- 包含社会学、教育学、文科等非理工科读者。

【要求】
1. 每个例子 / 类比应满足：
   - 与原概念有清晰的对应关系；
   - 例子本身不复杂，读起来不会增加额外负担；
   - 尽量贴近日常生活或常见技术场景（如推荐系统、搜索、排队、投票等）。

2. 风格要求：
   - 语气温和、像课堂讲解，不搞悬疑文学；
   - 描述控制在 1–3 段内，避免过长。

【输出格式】
请给出 2–3 个候选，每个按以下结构输出：

- 例子 X：
  1）例子描述：用于直接写入书稿的那种表述；
  2）对应关系说明：原概念中的关键要素 A/B/C，在这个例子里分别对应什么；
  3）（可选）适用位置建议：更适合作为引入？中间解释？还是小结回顾？

下面是需要用例子/类比来解释的概念或原文片段：
```
