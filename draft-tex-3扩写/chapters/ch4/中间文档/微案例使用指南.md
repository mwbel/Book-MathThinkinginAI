# 微案例环境使用指南

## 环境定义

微案例环境已经在主文件 `AImath.v6.tex` 中定义：

```latex
\begin{microcase}{标题内容}
    这里是微案例的具体内容...
    可以包含数学公式、列表、图片等任何LaTeX内容
\end{microcase}
```

## 视觉特性

### 设计特点
- **蓝色主题**：浅蓝色背景 + 深蓝色边框
- **专业外观**：圆角边框，轻微阴影效果
- **醒目标题**：白色标题栏，无衬线字体
- **内容友好**：适当的内边距，良好的可读性

## 使用示例

### 基础用法
```latex
\begin{microcase}{微案例：从像素到语义的抽象层次}
    让我们通过一个简单的手写数字识别问题来具象化这种层次化的抽象过程。

    \begin{itemize}
    \item 第一层抽象（数值化）：将灰度图像抽象为向量
    \item 第二层抽象（特征化）：提取边缘、角点等特征
    \item 第三层抽象（语义化）：映射到类别概率分布
    \end{itemize}
\end{microcase}
```

### 包含数学公式
```latex
\begin{microcase}{微案例：注意力机制的形式化}
    注意力机制的数学表达：
    $$\text{Attention}(Q,K,V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$$

    其中：
    \begin{itemize}
    \item $Q$：查询矩阵
    \item $K$：键矩阵
    \item $V$：值矩阵
    \end{itemize}
\end{microcase}
```

## 技术特性

- **自动分页**：`breakable` 选项确保长微案例可以跨页显示
- **阴影效果**：轻微的立体感增强视觉效果
- **响应式设计**：自动适应内容长度
- **兼容性**：与所有LaTeX包和环境兼容

## 最佳实践

### 1. 标题命名
- 使用描述性标题
- 格式：`微案例：具体主题`
- 长度适中，避免过长或过短

### 2. 内容组织
- 开头简要说明背景
- 中间详细阐述核心内容
- 结尾总结关键要点

### 3. 数学内容
- 合理使用数学公式
- 重要公式单独一行显示
- 必要时提供公式解释

### 4. 视觉层次
- 使用列表组织要点
- 重要概念用`\textbf`强调
- 保持段落长度适中

## 故障排除

### 常见问题
1. **环境未定义**：确保已加载必要的包
2. **跨页问题**：检查 `breakable` 选项
3. **标题格式**：确保标题不含特殊字符

### 调试建议
- 先在简单文档中测试
- 检查LaTeX日志文件
- 确保包版本兼容性
