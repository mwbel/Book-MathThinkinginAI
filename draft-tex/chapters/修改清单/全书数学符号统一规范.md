# 全书数学符号统一规范

## 1. 基本数学符号规范

### 1.1 数集表示
- 实数集：$\mathbb{R}$
- 自然数集：$\mathbb{N}$
- 整数集：$\mathbb{Z}$
- 复数集：$\mathbb{C}$
- 有理数集：$\mathbb{Q}$

### 1.2 向量和矩阵
- 向量：$\mathbf{x}, \mathbf{y}, \mathbf{w}$ （使用粗体小写字母）
- 矩阵：$\mathbf{X}, \mathbf{Y}, \mathbf{W}$ （使用粗体大写字母）
- 向量维度：$\mathbf{x} \in \mathbb{R}^n$
- 矩阵维度：$\mathbf{X} \in \mathbb{R}^{m \times n}$
- 转置：$\mathbf{X}^T$
- 逆矩阵：$\mathbf{X}^{-1}$

### 1.3 函数和映射
- 函数：$f: X \rightarrow Y$
- 复合函数：$(f \circ g)(x) = f(g(x))$
- 偏导数：$\frac{\partial f}{\partial x}$
- 梯度：$\nabla f$ 或 $\nabla_{\mathbf{x}} f$

## 2. 概率和统计符号

### 2.1 概率表示
- 概率：$P(X)$, $P(X = x)$
- 条件概率：$P(Y|X)$, $P(Y|X = x)$
- 联合概率：$P(X, Y)$
- 边际概率：$P(X) = \sum_y P(X, Y = y)$

### 2.2 分布和期望
- 期望：$\mathbb{E}[X]$, $\mathbb{E}_{x \sim P}[f(x)]$
- 方差：$\text{Var}[X]$ 或 $\sigma^2$
- 标准差：$\sigma$
- 协方差：$\text{Cov}(X, Y)$

### 2.3 信息论
- 熵：$H(X) = -\sum_i P(x_i) \log P(x_i)$
- 交叉熵：$H(p, q) = -\sum_i p_i \log q_i$
- KL散度：$D_{KL}(P||Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)}$
- 互信息：$I(X; Y)$

## 3. 机器学习专用符号

### 3.1 数据和特征
- 训练集：$\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^n$
- 输入特征：$\mathbf{x} \in \mathbb{R}^d$
- 输出标签：$y$
- 预测值：$\hat{y}$
- 样本数量：$n$ 或 $m$
- 特征维度：$d$

### 3.2 模型参数
- 参数向量：$\boldsymbol{\theta}$ 或 $\mathbf{w}$
- 偏置项：$b$
- 权重矩阵：$\mathbf{W}$
- 学习率：$\alpha$ 或 $\eta$
- 正则化参数：$\lambda$

### 3.3 损失函数和优化
- 损失函数：$\mathcal{L}(\boldsymbol{\theta})$ 或 $L(\mathbf{w})$
- 经验风险：$\hat{\mathcal{R}}(\boldsymbol{\theta})$
- 结构风险：$\mathcal{R}(\boldsymbol{\theta})$
- 目标函数：$J(\boldsymbol{\theta})$

## 4. 深度学习符号

### 4.1 神经网络结构
- 层数：$L$
- 第$l$层：上标 $(l)$
- 第$l$层神经元数：$n^{(l)}$
- 第$l$层输出：$\mathbf{h}^{(l)}$
- 激活函数：$\sigma(\cdot)$, $\text{ReLU}(\cdot)$, $\text{sigmoid}(\cdot)$

### 4.2 卷积神经网络
- 卷积操作：$*$
- 卷积核：$\mathbf{K}$
- 特征图：$\mathbf{F}$
- 池化操作：$\text{pool}(\cdot)$

### 4.3 循环神经网络
- 时间步：$t$
- 隐藏状态：$\mathbf{h}_t$
- 细胞状态：$\mathbf{C}_t$（LSTM）
- 输入门：$\mathbf{i}_t$
- 遗忘门：$\mathbf{f}_t$
- 输出门：$\mathbf{o}_t$

### 4.4 注意力机制
- 查询：$\mathbf{Q}$
- 键：$\mathbf{K}$
- 值：$\mathbf{V}$
- 注意力权重：$\boldsymbol{\alpha}$
- 注意力函数：$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V})$

## 5. 优化算法符号

### 5.1 梯度下降
- 梯度：$\nabla_{\boldsymbol{\theta}} \mathcal{L}$
- 更新规则：$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \alpha \nabla_{\boldsymbol{\theta}} \mathcal{L}$
- 动量：$\mathbf{v}_t$
- 动量系数：$\beta$

### 5.2 自适应优化
- Adam参数：$\beta_1, \beta_2$
- 一阶矩估计：$\mathbf{m}_t$
- 二阶矩估计：$\mathbf{v}_t$
- 偏差修正：$\hat{\mathbf{m}}_t, \hat{\mathbf{v}}_t$

## 6. 集合和逻辑符号

### 6.1 集合操作
- 属于：$\in$
- 不属于：$\notin$
- 子集：$\subset$
- 并集：$\cup$
- 交集：$\cap$
- 空集：$\emptyset$

### 6.2 逻辑符号
- 逻辑与：$\land$
- 逻辑或：$\lor$
- 逻辑非：$\neg$
- 蕴含：$\rightarrow$
- 等价：$\leftrightarrow$

## 7. 特殊函数和操作

### 7.1 常用函数
- 指示函数：$\mathbb{I}[\cdot]$ 或 $\mathbf{1}[\cdot]$
- 符号函数：$\text{sign}(\cdot)$
- 最大值：$\max(\cdot)$
- 最小值：$\min(\cdot)$
- 绝对值：$|\cdot|$
- 范数：$\|\cdot\|_p$

### 7.2 概率函数
- Softmax：$\text{softmax}(\mathbf{x})_i = \frac{\exp(x_i)}{\sum_j \exp(x_j)}$
- Sigmoid：$\sigma(x) = \frac{1}{1 + \exp(-x)}$
- ReLU：$\text{ReLU}(x) = \max(0, x)$

## 8. 算法复杂度表示

### 8.1 时间复杂度
- 大O记号：$O(n)$, $O(n^2)$, $O(\log n)$
- 大Ω记号：$\Omega(n)$
- 大Θ记号：$\Theta(n)$

### 8.2 空间复杂度
- 空间复杂度：$S(n) = O(n)$
- 辅助空间：$O(1)$

## 9. 公式编号和引用规范

### 9.1 编号格式
- 重要公式使用：`\begin{equation}\label{eq:label_name}`
- 多行公式使用：`\begin{align}\label{eq:label_name}`
- 引用格式：`公式~\ref{eq:label_name}`

### 9.2 标签命名规范
- 方程：`eq:descriptive_name`
- 定理：`thm:descriptive_name`
- 引理：`lem:descriptive_name`
- 定义：`def:descriptive_name`

## 10. 图表标注规范

### 10.1 图片标注
- 标签格式：`\label{fig:descriptive_name}`
- 引用格式：`图~\ref{fig:descriptive_name}`
- 说明文字：`\caption{详细说明}`

### 10.2 表格标注
- 标签格式：`\label{tab:descriptive_name}`
- 引用格式：`表~\ref{tab:descriptive_name}`
- 说明文字：`\caption{详细说明}`

## 11. 特殊领域符号

### 11.1 因果推理
- 干预：$\text{do}(X)$
- 因果图：$G$
- 混淆变量：$Z$
- 因果效应：$P(Y|\text{do}(X))$

### 11.2 强化学习
- 状态：$s \in \mathcal{S}$
- 动作：$a \in \mathcal{A}$
- 奖励：$r$
- 策略：$\pi(a|s)$
- 价值函数：$V(s)$
- Q函数：$Q(s, a)$

### 11.3 贝叶斯方法
- 先验：$P(\theta)$
- 似然：$P(D|\theta)$
- 后验：$P(\theta|D)$
- 证据：$P(D)$
- 贝叶斯因子：$BF$

## 12. 使用指南

### 12.1 符号选择原则
1. **一致性**：同一概念在全书中使用相同符号
2. **标准性**：遵循学术界通用的符号约定
3. **清晰性**：避免符号歧义和重复使用
4. **简洁性**：选择简洁明了的符号表示

### 12.2 新符号引入规范
1. 首次使用时明确定义
2. 在符号表中记录
3. 确保与现有符号不冲突
4. 考虑国际通用性

- [ ] 符号定义是否明确
