# 任务说明
本任务将依次对以下章节进行层级压缩控制。
目前部分章节层级深达 4–5 级（如 4.1.1.3.2.1），会影响可读性与教材排版；
建议将层级控制在**最多三级**：章 → 节 → 小节；
将部分子节内容（如算法细节、例子）整合为“案例框”或“延伸阅读框”。

# 模型设置
