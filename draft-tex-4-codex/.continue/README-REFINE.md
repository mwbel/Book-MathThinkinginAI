# /refine Slash Command 使用说明

## 功能说明
`/refine` 命令是一个专业的中文教材文本润色工具，专门用于优化成熟草稿，提升文本的教学效果和可读性。

## 使用方法
1. 在Continue的输入界面中输入 `/refine`
2. 在命令后添加需要润色的文本
3. 系统会自动应用专业编辑标准进行优化

## 示例
```
/refine 这里是需要润色的文本内容...
```

## 编辑标准
- 保持LaTeX格式和语法不变
- 输出带diff视图的文件片段
- 每段不超过7行
- 语气自然、有层次、有留白
- 类似《数学之美 × 通识教育》的调性
- 保留课堂讲解的自然呼吸感

## 配置文件位置
- 主配置：`.continue/.config.json`
- 详细说明：`.continue/slash-commands.yaml`

## 注意事项
- 重启Continue IDE后生效
- 确保配置文件格式正确
- 支持LaTeX格式的文本处理
