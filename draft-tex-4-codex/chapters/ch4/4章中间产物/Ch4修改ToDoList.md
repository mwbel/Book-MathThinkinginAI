```latex
\textbf{缓存友好性：算法性能的隐形杀手}

现代计算机的性能瓶颈往往不在CPU运算速度，而在内存访问延迟。L1缓存访问约1纳秒，主内存访问需100纳秒——相差100倍！

以矩阵乘法为例，朴素实现 $C_{ij} = \sum_k A_{ik}B_{kj}$ 对矩阵B按列访问，严重违背缓存局部性。\textbf{分块矩阵乘法}通过重组计算顺序，将矩阵切分为小块（如64×64），使每块完全放入缓存，性能可提升3-5倍。这种"同样的数学运算，不同的访问顺序，迥异的性能"深刻体现了算法思维必须理解硬件特性。
```

**B. 新增：算法选择决策框架**（插入412行之后）
**新增**: 7行

```latex
\textbf{算法选择的决策框架}

面对线性方程组 $Ax=b$，算法工程师需要系统性决策：
\begin{itemize}
\item 规模小($n < 1000$)且稠密 → LU分解（$O(n^3)$，精度高）
\item 规模大($n > 10^6$)且稀疏 → 迭代法（CG/GMRES，$O(n)$空间）
\item 矩阵对称正定 → Cholesky分解（速度快一倍）
\item 矩阵病态($\kappa(A) > 10^{10}$) → 预处理+迭代精化
\item 特殊结构（循环、Toeplitz）→ FFT加速（$O(n\log n)$）
\end{itemize}
```

```latex
\textbf{Kahan求和算法：补偿舍入误差的精妙设计}

考虑计算 $\sum_{i=1}^{10^6} 1.0$ 在单精度浮点下的结果。理论上是 $10^6$，但朴素累加会因舍入误差积累得到错误结果。当sum变大后，$\text{sum} + 1.0$ 中的1.0会因精度不足被"吞掉"。

\textbf{Kahan补偿求和}通过额外变量记录"丢失的误差"，将误差从 $O(n\epsilon)$ 降至 $O(\epsilon)$：
$$\begin{aligned}
y &= x_i - c \\
t &= \text{sum} + y \\
c &= (t - \text{sum}) - y \\
\text{sum} &= t
\end{aligned}$$
这提醒我们：在数学上加法满足结合律，但在浮点运算中 $(a+b)+c \neq a+(b+c)$。
```
**新增**: 10行

```latex
\subsection{算法思维在深度学习中的体现}

深度学习的成功不仅源于数学理论，更依赖算法工程师对计算特性的深刻理解。

\subsubsection{Softmax的数值稳定化}

原始Softmax公式 $\text{softmax}(x_i) = \frac{e^{x_i}}{\sum_{j} e^{x_j}}$ 在数学上完美，但计算中隐藏致命缺陷：当 $x_i$ 很大时（如100），$e^{100} \approx 10^{43}$ 导致溢出；当 $x_i$ 很小时（如-100），$e^{-100}$ 导致下溢。

\textbf{数值稳定版本}利用Softmax的平移不变性：
$$\text{softmax}(x_i) = \frac{e^{x_i - \max(x)}}{\sum_{j} e^{x_j - \max(x)}}$$

减去最大值后，指数项最大值为 $e^0 = 1$，其余在 $(0,1)$ 之间，完美避免溢出。

\textbf{算法洞察}：
- 数学等价：$\text{softmax}(x) = \text{softmax}(x + c)$ 对任意常数$c$成立
- 计算优化：选择 $c = -\max(x)$，将所有指数项控制在安全范围
- 额外成本：仅为 $O(n)$ 的求最大值，换来绝对的数值稳定性

这完美诠释了算法思维的精髓：\textit{在数学等价的多种形式中，选择计算最稳定的那一个}。
```
